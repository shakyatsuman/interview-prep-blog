Trees & DFS

Every tree problem is a recursion problem. The recursive structure of a binary tree maps directly onto recursive thinking — master DFS traversal order and the BST invariant and most tree problems become pattern-matching.

⏱ 6 min read 🌲 Trees 🔑 Java 8 📈 Intermediate → Advanced

A binary tree is a linked list where each node has two pointers instead of one — left and right instead of next. The pointer manipulation skills from Post #9 transfer directly. The difference is that traversal now branches, and the call stack handles the branching for you when you write recursive solutions. Understanding why recursion works on trees — and what base case to return — is the central skill this post develops.

Prerequisites

Post #9 (Linked Lists) — node-based pointer thinking. A TreeNode is structurally a ListNode with two next pointers.

Three DFS Traversals

Depth-first search visits every node by going deep before going wide. The three DFS traversals differ only in when the current node is processed relative to its children.

Fig 1. Three DFS traversals on the same tree. The only difference is when the current node is processed relative to its children.

Java 8// All three DFS traversals — only the processing order changes
void preorder(TreeNode node) {
    if (node == null) return;
    process(node);            // root first
    preorder(node.left);
    preorder(node.right);
}

void inorder(TreeNode node) {
    if (node == null) return;
    inorder(node.left);
    process(node);            // root between children
    inorder(node.right);
}

void postorder(TreeNode node) {
    if (node == null) return;
    postorder(node.left);
    postorder(node.right);
    process(node);            // root last
}

The BST Invariant

A binary search tree is a binary tree with one additional constraint: for every node, all values in its left subtree are strictly less than the node's value, and all values in its right subtree are strictly greater. This invariant holds recursively at every node — not just between a parent and its immediate children.

The invariant buys two things. First, BST inorder traversal always produces a sorted sequence — which is why inorder is the natural traversal for BST problems. Second, search can prune one branch at every node — rather than visiting all n nodes, you follow the invariant left or right, reducing search to O(h) instead of O(n).

Fig 2. BST invariant: each node inherits bounds from its ancestors. Every node in the left subtree of 8 is less than 8; every node in the right subtree is greater — recursively at every level. Inorder traversal always yields a sorted sequence.

Example 1 — Maximum Depth of Binary Tree

LeetCode #104 · Easy · Postorder DFS

Given the root of a binary tree, return its maximum depth — the number of nodes along the longest path from root to a leaf node.

Example

root = [3,9,20,null,null,15,7] → 3

The maximum depth of a tree rooted at any node is 1 + the maximum depth of its deeper subtree. This is a postorder pattern: compute the answer for both children first, then combine at the parent. The base case is a null node, which has depth 0.

Fig 3. Tree structure for Max Depth. The highlighted path shows the maximum-depth route. maxDepth returns 1 + max(left, right) at every node — at node 3: 1 + max(1, 2) = 3.

Java 8public int maxDepth(TreeNode root) {
    if (root == null) return 0;       // base case: null node has depth 0

    int left  = maxDepth(root.left);   // depth of left subtree
    int right = maxDepth(root.right);  // depth of right subtree

    return 1 + Math.max(left, right);  // current node adds 1
}
// Time: O(n)  |  Space: O(h)  where h = tree height
The Recursive Leap

Trust the recursion. maxDepth(root.left) correctly returns the depth of the entire left subtree — you don't need to think about how. Your only job is: what does this function return for the current node, given correct answers from its children? That question has a one-line answer: 1 + max(left, right).

Example 2 — Lowest Common Ancestor

LeetCode #236 · Medium · Postorder DFS

Given a binary tree and two nodes p and q, find their lowest common ancestor — the deepest node that has both p and q as descendants (a node can be a descendant of itself).

Example

Tree: [3,5,1,6,2,0,8,null,null,7,4]
p=5, q=4 → 5 (5 is an ancestor of 4)
p=5, q=1 → 3 (3 is the first node with both in different subtrees)

The key insight: if p is found in the left subtree and q in the right (or vice versa), the current node is the LCA. If both are in the same subtree, the answer is deeper. Postorder DFS propagates found nodes upward naturally.

Fig 4. LCA on the example tree. When targets split across left and right subtrees, the split point is the answer. When one target is an ancestor of the other, the ancestor is the answer.

Java 8public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    if (root == null) return null;           // not found in this subtree
    if (root == p || root == q) return root;  // found one target

    TreeNode left  = lowestCommonAncestor(root.left,  p, q);
    TreeNode right = lowestCommonAncestor(root.right, p, q);

    if (left != null && right != null) return root;  // split: root is LCA
    return left != null ? left : right;   // propagate the found node upward
}
// Time: O(n)  |  Space: O(h)

Example 3 — Validate Binary Search Tree

LeetCode #98 · Medium · BST invariant + DFS

Given the root of a binary tree, determine whether it is a valid BST. A valid BST requires that every node in the left subtree is strictly less than the current node, and every node in the right subtree is strictly greater — not just the immediate children.

Common Mistake

Checking only immediate children (left.val < root.val) is wrong. A node deep in the right subtree might still violate the root's constraint. The correct approach passes valid bounds down the tree at every recursive call.

Fig 5. Left: valid BST — every node satisfies its inherited bounds. Right: invalid BST — node 4 is in the right subtree of 5 but 4 < 5, violating the lower bound (5, +∞).

Java 8public boolean isValidBST(TreeNode root) {
    return validate(root, Long.MIN_VALUE, Long.MAX_VALUE);
}

private boolean validate(TreeNode node, long min, long max) {
    if (node == null) return true;
    if (node.val <= min || node.val >= max) return false;

    return validate(node.left,  min,       node.val)  // left: upper bound tightens
        && validate(node.right, node.val,  max);      // right: lower bound tightens
}
// Time: O(n)  |  Space: O(h)
Why Long.MIN_VALUE / Long.MAX_VALUE

Using long bounds rather than int avoids overflow when node values are Integer.MIN_VALUE or Integer.MAX_VALUE — a common edge case in BST validation.

Universal Template

The three DFS skeletons that cover most tree problems:

Java 8 — Pattern 1: Postorder (combine results from children)int dfs(TreeNode node) {
    if (node == null) return BASE_CASE;
    int left  = dfs(node.left);
    int right = dfs(node.right);
    return combine(left, right, node.val);  // e.g. 1 + max(left, right)
}
Java 8 — Pattern 2: Preorder (pass state down)void dfs(TreeNode node, int state) {
    if (node == null) return;
    int newState = update(state, node.val);  // e.g. state + node.val
    dfs(node.left,  newState);
    dfs(node.right, newState);
}
Java 8 — Pattern 3: BST search (prune one branch)TreeNode search(TreeNode node, int target) {
    if (node == null || node.val == target) return node;
    if (target < node.val) return search(node.left,  target);
    else                   return search(node.right, target);
}

When to Reach for Tree DFS

  • Any problem on a binary tree where you need to visit all nodes — DFS with the right traversal order
  • "Max/min path", "sum of path", "diameter" — postorder: compute at children, combine at parent
  • "Build/serialize/reconstruct" a tree — preorder: process root before children
  • "Validate BST", "search BST", "insert BST" — use the BST invariant to prune one branch
  • "Lowest Common Ancestor" — postorder propagation of found nodes upward

Learning Path

LC 124 (Binary Tree Maximum Path Sum) is the most challenging problem in this set. It requires understanding that a path through a node can use both children for the global answer, but only one child when propagating upward to the parent. If you can derive it without hints, postorder DFS is truly internalized. Try it before moving to Post #11.
