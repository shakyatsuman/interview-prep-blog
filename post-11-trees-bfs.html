Trees & BFS

When DFS recurses, BFS queues. Replace the implicit call stack with an explicit queue and tree traversal becomes level-by-level — unlocking right-side views, zigzag patterns, and level-maximum problems that DFS cannot express as cleanly.

⏱ 5 min read 🌲 Trees 🔑 Java 8 📈 Intermediate → Advanced

Post #10 solved tree problems by going deep — following one branch all the way to a leaf before backtracking. BFS goes wide instead: it visits every node at depth 1 before any node at depth 2, every node at depth 2 before any at depth 3, and so on. The mechanism is an explicit queue. Enqueue the root, then repeatedly dequeue a node, process it, and enqueue its children. The FIFO ordering guarantees level-by-level traversal automatically.

Prerequisites

Post #10 (Trees & DFS) — tree structure, TreeNode, and recursive traversal. Post #8 (Stacks & Queues) — queue operations.

The Core Pattern

Every BFS tree problem follows the same skeleton. The key detail is capturing the queue size at the start of each iteration. That snapshot tells you how many nodes belong to the current level so you can process them as a group before moving to the next.

Java 8 — BFS skeletonQueue<TreeNode> queue = new LinkedList<>();
queue.offer(root);

while (!queue.isEmpty()) {
    int size = queue.size();          // snapshot: nodes in this level
    for (int i = 0; i < size; i++) {
        TreeNode node = queue.poll();
        // process node
        if (node.left  != null) queue.offer(node.left);
        if (node.right != null) queue.offer(node.right);
    }
    // level boundary: all nodes at this depth processed
}
DFS vs BFS

DFS — recursive call stack, depth-first, natural for path, ancestor, and subtree problems.
BFS — explicit queue, level-first, natural for level grouping, distance, and shortest-path problems.
Neither is universally better — the problem structure determines the choice.

Example 1 — Binary Tree Level Order Traversal

LeetCode #102 · Medium · BFS level grouping

Given the root of a binary tree, return the level order traversal of its node values — a list of lists, one per level, from left to right.

Example

Tree [3, 9, 20, null, null, 15, 7] → [[3], [9, 20], [15, 7]]

Fig 1. BFS level-order trace. The queue size snapshot at the start of each outer iteration determines which nodes belong to the current level.

Java 8public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> result = new ArrayList<>();
    if (root == null) return result;

    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);

    while (!queue.isEmpty()) {
        int size = queue.size();
        List<Integer> level = new ArrayList<>();

        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            level.add(node.val);
            if (node.left  != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        result.add(level);
    }
    return result;
}
// Time: O(n)  |  Space: O(w)  where w = max width of tree

Example 2 — Binary Tree Right Side View

LeetCode #199 · Medium · BFS last-node-per-level

Given the root of a binary tree, imagine standing to its right. Return the values of the nodes visible from the right side, from top to bottom.

Example

Tree [1, 2, 3, null, 5] → [1, 3, 5]
At level 3, only node 5 is visible — node 3 has no children on the left of 5.

Fig 2. Right side view. Highlighted nodes (darker blue) are the last in each BFS level — the only ones visible from the right. Node 2 is hidden behind node 3.

Java 8public List<Integer> rightSideView(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    if (root == null) return result;

    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);

    while (!queue.isEmpty()) {
        int size = queue.size();
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            if (i == size - 1) result.add(node.val);  // last node in level
            if (node.left  != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
    }
    return result;
}
// Time: O(n)  |  Space: O(w)
Variants from the same skeleton

Left side view — record i == 0 instead of i == size - 1.
Max level sum — accumulate sum inside inner loop, record max after.
Average of levels — sum inside inner loop, divide by size after.

Example 3 — Binary Tree Zigzag Level Order

LeetCode #103 · Medium · BFS with direction flag

Given the root of a binary tree, return its zigzag level order traversal — left-to-right for odd levels, right-to-left for even levels, alternating.

Example

Tree [3, 9, 20, null, null, 15, 7] → [[3], [20, 9], [15, 7]]
Level 2 is reversed: 20 appears before 9.

BFS collects each level normally. A boolean flag tracks direction. When reversing, insert each value at the front of the level list using addFirst() instead of addLast(). Toggle the flag after each level.

Fig 3. Zigzag traversal. Odd levels use addLast (blue, left→right); even levels use addFirst (orange, right→left). The BFS queue order stays unchanged — only the insertion end alternates.

Java 8public List<List<Integer>> zigzagLevelOrder(TreeNode root) {
    List<List<Integer>> result = new ArrayList<>();
    if (root == null) return result;

    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    boolean leftToRight = true;

    while (!queue.isEmpty()) {
        int size = queue.size();
        LinkedList<Integer> level = new LinkedList<>();

        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            if (leftToRight) level.addLast(node.val);
            else             level.addFirst(node.val);  // insert at front to reverse
            if (node.left  != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        result.add(level);
        leftToRight = !leftToRight;  // toggle direction each level
    }
    return result;
}
// Time: O(n)  |  Space: O(w)

Universal Template

All BFS tree problems are variations of this single skeleton — only what happens inside the inner loop changes:

Java 8 — BFS universal templateQueue<TreeNode> queue = new LinkedList<>();
queue.offer(root);
int level = 0;

while (!queue.isEmpty()) {
    int size = queue.size();          // nodes at current level
    for (int i = 0; i < size; i++) {
        TreeNode node = queue.poll();

        // i == 0        → first node (left side view)
        // i == size - 1 → last node  (right side view)
        // accumulate    → sum, max, average per level
        // addFirst/Last → zigzag direction

        if (node.left  != null) queue.offer(node.left);
        if (node.right != null) queue.offer(node.right);
    }
    level++;
}

Space Note

Space is O(w) where w is the maximum tree width. For a balanced binary tree the last level holds up to n/2 nodes, so O(w) = O(n) in the worst case. This contrasts with DFS which uses O(h) stack space — O(log n) balanced, O(n) skewed.

When to Reach for BFS

  • "Level order" output, or any result grouped by depth — BFS with size snapshot
  • "Right/left side view" — last/first node per level
  • "Maximum / minimum / average per level" — aggregate inside the inner loop
  • "Zigzag" or alternating direction — BFS with direction flag
  • "Shortest path" in an unweighted graph or grid — BFS guarantees minimum distance
